Parent banners

Every banner and inline notice a signed-in parent can be shown, across both the coaching and non-coaching personas, with the condition that fires it. Linked from nowhere — open it by URL. This is a static rendering, so it has to be kept in step with app.js by hand.

Page level

Answer confirmation Fires when: an answer is given or changed. Announced once with role="status", then fades on its own. It never persists for the visit — there is no standing "everything answered" banner. Reachable: all three personas, on answering
